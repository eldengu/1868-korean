'1868'은 메이지 유신이 일어난 해입니다.

## 번역 원칙

- **원문에서 직접 번역합니다.** 퍼블릭 도메인 원문만 사용합니다.
- **기존 한국어 번역본은 베끼지 않습니다.** 일본어 현대어역(現代語訳)이나 현대 주석본의 해설도 쓰지 않습니다.
- **쉬운 현대 한국어로 씁니다.** 소리 내어 읽기 좋은 ~합니다 체를 씁니다.
- **용어집을 둡니다.** 작품마다 용어집을 만들어 같은 말은 같은 번역어로 옮깁니다.
- **조 번호와 구성을 원문과 맞춥니다.** 한국어 문장을 원문과 바로 대조할 수 있습니다.
- **역사적 맥락을 중립적으로 밝힙니다.** 정한론, 한국 통감부 등 한국 근대사와 얽힌 인물의 글에는 짧고 중립적인 배경 설명을 붙입니다. 이 번역은 역사 자료를 소개하려는 것이며, 특정 인물이나 주장을 지지하거나 미화하지 않습니다.

## 원문 출처와 저작권

- 원문은 [아오조라 문고(青空文庫)](https://www.aozora.gr.jp/)와 [국립국회도서관 디지털 컬렉션](https://dl.ndl.go.jp/)의 메이지 시대 판본을 사용합니다.
  - 난슈 옹 유훈: [아오조라 문고 「遺訓」 도서 카드](https://www.aozora.gr.jp/cards/001320/card47885.html) (입력: 田中哲郎, 교정: 川山隆). 참고할 만한 메이지 판본으로 [NDL 1893년 판](https://dl.ndl.go.jp/pid/781424)이 있습니다.
  - 민권자유론: [NDL 디지털 컬렉션 『民権自由論』(集文堂, 1879년 4월)](https://dl.ndl.go.jp/pid/783715)의 사진을 보고 옮겨 적은 텍스트를 썼습니다. 텍스트와 판독이 불확실한 글자 목록은 `minken-jiyuron/source/`에 있습니다.
- 이 저장소의 원저자들은 모두 1909년 이전에 세상을 떠났습니다. 원문은 **일본·미국·한국에서 모두 퍼블릭 도메인**입니다.
  - 일본: 보호기간(사망 후 50년, 2018년부터 70년)이 이미 끝났습니다.
  - 미국: 1931년 이전에 출판된 저작물입니다.
  - 한국: 사망 후 70년이 지났습니다.
- 현대 판본의 주석, 해설, 현대어역은 저작권이 있을 수 있어 사용하지 않습니다.
