# 『민권자유론(民權自由論)』 용어집

번역에 쓴 낱말을 정리했습니다. 한 원어는 본문 전체에서 같은 번역어로 옮겼습니다.

| 원어 | 읽기(일본어) | 한국어 번역어 | 짧은 설명 |
|---|---|---|---|
| 民權自由論 | みんけんじゆうろん | 민권자유론 | 책 제목. 백성의 권리를 펴서 자유를 넓히자는 논설. |
| 民權 | みんけん | 민권(백성의 권리) | 백성이 나라에서 가지는 권리. "민권을 편다(張る)"로 즐겨 쓰임. |
| 自由 | じゆう | 자유 | 하늘이 사람에게 준 것. 목숨·재능보다 소중하다고 함. |
| 自由の權 | じゆうのけん | 자유의 권리 | 자유를 누리고 지킬 권리. 줄여 "자유권"이라 하지 않고 풀어서 씀. |
| 權利 | けんり | 권리 | 같은 뜻의 權理도 "권리"로 통일. 「權利自由」는 "권리와 자유". |
| 權理 | けんり | 권리 | 權利의 다른 표기. |
| 同權 | どうけん | 같은 권리(동권) | 모든 사람이 똑같이 가지는 권리. 부록 노래에 나옴. |
| 自主 | じしゅ | 자주 | 스스로 주인이 되는 것. 「自主自由」는 "자주와 자유". |
| 自主獨立 | じしゅどくりつ | 자주독립 | 스스로 서고 남에게 기대지 않음. |
| 國權 | こっけん | 국권(나라의 권리) | 나라가 밖으로 세우는 권위와 권리. |
| 獨立 | どくりつ | 독립 | 남에게 기대지 않고 홀로 섬. 사람과 나라 모두에 씀. |
| 政府 | せいふ | 정부 | 나라의 일을 맡은 곳. 우에키는 "회소(사무소)"라고도 부름. |
| 政事・政治 | せいじ | 정치 | 나라를 다스리는 일. 「政事は人民の事」. |
| 政體 | せいたい | 정체(정치의 체제) | 立憲政體, 專制政體처럼 나라를 다스리는 틀. |
| 人民 | じんみん | 인민 | 나라를 이루는 사람들. 책의 중심 말. |
| 民 | たみ・みん | 백성 | 「民權」 같은 한자어에서는 "민". 단독으로는 "백성". |
| 平民 | へいみん | 평민 | 일반 서민. 우에키는 "일본의 평민"이 기운이 없다고 꾸짖음. |
| 士族 | しぞく | 사족 | 옛 무사 계층 출신. 우에키 자신도 고치현 사족. |
| 新平民 | しんへいみん | 새로 평민이 된 분들 | 1871년 해방령으로 천민 신분에서 벗어난 분들을 가리킨 당시 말. 차별적 낙인이 있어 현대어에서는 쓰지 않으며, 번역은 중립적으로 풀어 옮김(notes 참조). |
| 國會 | こっかい | 국회 | 나라의 의회. |
| 民選議院 | みんせんぎいん | 민선의원(백성이 뽑는 의회) | 1870년대 민권 운동의 요구. 부록 노래에 나옴. |
| 憲法 | けんぽう | 헌법 | 나라의 가장 큰 뿌리 규칙. 國憲·根本律法도 같은 뜻. |
| 立憲 | りっけん | 입헌 | 헌법을 세워 그에 따라 다스림. 「立憲自由の政體」. |
| 專制 | せんせい | 전제 | 군주·정부가 홀로 제멋대로 다스림. |
| 壓制 | あっせい | 압제 | 힘으로 눌러 억누름. 厭制·壓制束縛도 같은 계열로 옮김. |
| 暴虐 | ぼうぎゃく | 포악 | 정부의 난폭하고 잔인한 다스림. |
| 束縛 | そくばく | 속박 | 자유를 묶음. |
| 天 | てん | 하늘 | (난슈 용어집과 동일) 사람을 낳고 권리를 내리는 근원. |
| 天の賜 | てんのたまもの | 하늘이 주신 선물 | 자유는 하늘이 내려 주신 것. 賜ふる도 같은 뜻. |
| 卑屈 | ひくつ | 비굴 | 남에게 굽신거리며 기가 꺾인 모습. 우에키가 가장 꾸짖는 마음가짐. |
| 文明開化 | ぶんめいかいか | 문명개화 | 문명(난슈 용어집과 동일)이 열리고 깨어남. 「文明の喰いつぶし」 등. |
| 文明 | ぶんめい | 문명 | (난슈 용어집과 동일) |
| 義務 | ぎむ | 의무 | 권리와 짝을 이루는 해야 할 일. |
| 幸福安樂 | こうふくあんらく | 행복과 안락 | 자유가 있어야 얻는다고 하는 목적. |
| 國家 | こっか | 국가 | 나라를 하나의 공동체로 부를 때. 「國家の良民」. |
| 國 | くに | 나라 | 백성이 모여 이룬 것. 정부가 만든 것이 아니라고 함. |
| 公け | おおやけ | 공적인 일(공공) | 나라와 모두에 관한 일. 「公けの憲法」=공적인 헌법. |
| 會所 | かいしょ | 사무소 | 정부를 "일 보는 사무소"에 빗댄 우에키의 말. |
| 役人 | やくにん | 관리 | 정부에 고용되어 일하는 사람. 백성이 "고용한" 사람이라고 함. |
| 奴隷 | どれい | 노예 | 卑屈의 극단. 「卑屈の奴隷」. |
| 良民 / 死民 | りょうみん / しみん | 좋은 백성 / 죽은 백성 | 國家の良民 ↔ 國家の死民. |
| 愛國心 | あいこくしん | 애국심 | 나라를 아끼는 마음. |
| 君主 | くんしゅ | 군주 | 임금. 帝王·王·君·帝도 문맥에 맞게 임금·왕·황제로 옮김. |
| 世の事・國の事 | よのこと・くにのこと | 세상일·나랏일 | 「國の事に心を用ひる」=나랏일에 마음을 쓰다. |
| 法律 | ほうりつ | 법률 | 자유를 지키려고 세운 규칙. |
| 才力 | さいりょく | 재능과 힘 | 하늘이 사람에게 나눠 준 재주와 힘. |
| 國憲 / 根本律法 | こっけん / こんぽんりっぽう | 국헌 / 근본율법 | 憲法의 다른 이름. 제4에 나옴. |
| 專制獨裁 | せんせいどくさい | 전제독재 | 제3. |
| 正理 | せいり | 바른 이치 | 제3. 「正理の行はれざる間は皆亂」. |
| 亂 | らん | 난(어지러움) | 전쟁만이 아니라 바른 이치가 행해지지 않는 상태 전체. |
| 牧民 / 人牧 | ぼくみん / じんぼく | 목민 / 인목(人牧) | 백성을 가축처럼 친다는 옛 정치관. 제2. |
| 唯々諾々 | いいだくだく | 네네 하며 따름 | 비굴의 모습. |
| 勤王の士 | きんのうのし | 왕실을 받드는 지사 | 막부 말기의 존왕파. 제2. |
| 養生 | ようじょう | 양생 | 몸을 돌보는 법. 제4의 비유. |
| 氣脈 | きみゃく | 기맥 | 정부와 인민 사이에 통하는 기운. |
| 無敵軍 | むてきぐん | 무적함대 | 1588년 스페인 함대. 제4(속). |
| 公論 | こうろん | 공론 | 인민의 여론. 제5. |
| 三千五百萬 | さんぜんごひゃくまん | 삼천오백만 | 당시 일본 인구. 머리말 서명과 부록 노래. |

## 비고
- 天=하늘, 政府=정부, 文明=문명은 같은 저장소의 『난슈 옹 유훈』 용어집과 같은 번역어입니다.
- 서양 인명·지명은 표준 표기를 썼습니다: 루소, 네로, 칼리굴라, 마리우스, 존 왕, 마그나카르타, 러니미드, 카이사르, 루이 16세, 찰스 1세, 루이 14세, 니콜라이, 메테르니히, 엘리자베스 여왕, 링컨, 수어드 등.
- 책 제목 「民權自由論」은 "민권자유론".
